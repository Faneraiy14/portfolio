## Nyxilum — власна мова програмування

Компілятор у байткод + стекова VM з нуля, з власною стандартною
бібліотекою й пакетним менеджером. Самохостована — власний інтерпретатор
написаний тією самою мовою.

- **[NyxilumLang](https://github.com/Faneraiy14/NyxilumLang)** — сама мова: компілятор, VM, понад 200 вбудованих функцій (математика, рядки, HTTP + WebSocket-сервер, кросплатформне 2D-полотно з власним растровим шрифтом і подіями миші/клавіатури поверх власного X11-клієнта без жодних бібліотек, GUI, конкурентність, вбудована БД, керування процесами ОС, zip/regex). Ще вміє компілюватись напряму в машинний код, взагалі без VM: у x86 — реальні модулі власного pet-OS-ядра написані нею, скомпільовані так і завантажуються в QEMU — і в ARM64 для телефонів на Android/Linux (динамічні значення, більша частина нативної стандартної бібліотеки написана самою NyxilumLang, перевірено на справжньому телефоні). Android-застосунки будуються поверх маленького незмінного Java-«перекладача», а вся логіка застосунку — на NyxilumLang. Має власні клієнти PostgreSQL і MySQL/MariaDB, написані на самій мові поверх голого TCP — разом з авторизацією SCRAM-SHA-256 / caching_sha2 і всією криптою (SHA-1/SHA-256/MD5/HMAC/PBKDF2) без жодної нативної бібліотеки.
- **[NyxilumIDE](https://github.com/Faneraiy14/NyxilumIDE)** — середовище програмування для новачків і не тільки, написане **на самій NyxilumLang** (`nx ide`). Два режими: **блоки** як у Scratch (палітра, перетягування з прилипанням, програма з блоків перетворюється на справжній код) і **код** (підсвітка, автодоповнення, пошук, автовідступи, консоль, у якій програма питає й отримує відповіді). Екскурсія по IDE, уроки з автоперевіркою і кнопкою «Покажи мені» (IDE сама рухає курсор і складає програму), приклади-ігри, підказки до помилок простими словами («може, ти мав на увазі ...?») і вшита історія версій з diff — маленький git для підготовки до справжнього.
- **[NyxilumDb](https://github.com/Faneraiy14/NyxilumDb)** — вбудована key-value база даних, на якій працює `dbOpen()` у NyxilumLang, з WAL-довговічністю.
- **[NyxilumNode](https://github.com/Faneraiy14/NyxilumNode)** — самостійний рантайм (`nx файл.nx`), плюс пакетний менеджер (`nx install owner/repo`). Готовий `.exe` — .NET встановлювати не треба.
- **[NyxilumMcp](https://github.com/Faneraiy14/NyxilumMcp)** — MCP-сервер, щоб AI-асистент міг компілювати, запускати, лінтити й вести REPL-сесію з `.nx`-кодом напряму, у пісочниці.
- **[nyxilum-assert](https://github.com/Faneraiy14/nyxilum-assert)** — бібліотека тверджень для тестування коду NyxilumLang.
- **[NyxilumEngine](https://github.com/Faneraiy14/NyxilumEngine)** — невеликий 2D ігровий рушій, GameObject/Component-стиль, повністю скриптований самою NyxilumLang (без вбудованої чужої мови скриптів) — з робочим прикладом-грою "ухилення від блоків, що падають". Сама логіка рушія (GameObject/Scene/колізії) — звичайний, кросплатформний NyxilumLang-код; лише реальне вікно гри потребує Windows (Windows Forms).
- **[nyxilum-engine-mcp](https://github.com/Faneraiy14/nyxilum-engine-mcp)** — MCP-сервер для NyxilumEngine — запуск прикладів/тестів рушія й довідник API напряму.

## NyxOS — власна операційна система

Ядро з нуля на C + асемблері, без Linux/BSD чи будь-якого існуючого
ядра під капотом — не заради практичності, а щоб контролювати кожен
рівень системи особисто, від першого байта після завантажувача.
Переривання, менеджер фізичної пам'яті й paging, власна файлова
система NyxFS, Ring 3 (userspace) з витіснювальним планувальником,
графічний VESA/GOP-режим із менеджером вікон і робочим столом, мережа
(PCI/RTL8139/lwIP — DHCP/DNS/TCP/HTTP), власний формат пакетів і
пакетний менеджер, найпростіший браузер, акаунти користувачів, GPT-
інсталятор на реальний диск, USB (UHCI) з реальними HID-клавіатурою
й мишею (boot protocol), справжнє ACPI-вимкнення/перезавантаження,
що працює й під UEFI (через Multiboot2-передачу від GRUB), і міні-
бібліотека C для user-простору з файловими syscall'ами — тож програми
пишуться звичайним C поверх NyxFS, а не вручну асемблером.

- **[NyxOS-releases](https://github.com/Faneraiy14/NyxOS-releases)** — готовий ISO для завантаження на флешку; вихідний код лежить в окремому приватному репо.

## FL Launcher

Minecraft-лаунчер (Electron), який я активно розробляю й доставляю реальним
користувачам на Windows і Linux. Гра стартує окремим процесом, тож лаунчер
можна закрити під час гри; завантажені збірки запускаються без інтернету;
інтерфейс має темну/світлу тему з акцентним кольором і вбудований гайд.
Серверна частина (Express + PostgreSQL) дає необов'язковий акаунт лаунчера
з косметикою, внутрішньою валютою, кейсами й щоденним колесом.
Ще в ньому: вбудована оптимізація й ремонт збірок, знімки з відкатом, коди
збірок, клієнт у грі та друзі з чатом, історія якого лежить лише на
комп'ютері користувача. **[Повний список можливостей](https://github.com/Faneraiy14/fl-launcher/blob/main/FEATURES.uk.md)**.

- **[fl-launcher](https://github.com/Faneraiy14/fl-launcher)** — канал релізів (`.exe`, `.AppImage`, `.deb` з автооновленням); вихідний код лежить в окремому приватному репо.
- **[fl-bridge](https://github.com/Faneraiy14/fl-bridge)** — релізи `FLBridge.jar`, мод-лоадера, який FL Launcher завантажує й оновлює автоматично; підтримує Minecraft від 1.14.4 до найновіших 26.x на Java 8–25 (ASM-хуки обираються під версію гри, перевірено матрицею версій).
- **[fl-mods](https://github.com/Faneraiy14/fl-mods)** — готові моди для FL Loader (зум, показ ситості, таймери ефектів, інфо про блок, міцність та інше), один jar на мод для Minecraft 1.14.4–26.3, ставляться з вікна «Моди» лаунчера; лише релізи, код приватний.
- **[FL-Skin-Studio-releases](https://github.com/Faneraiy14/FL-Skin-Studio-releases)** — FL Skin Studio, редактор скінів для Windows і Linux (2D-розгортка + 3D-малювання, шари, обмін із Blockbench); скіни зберігаються прямо в лаунчер. Вихідний код приватний.

## Якість коду

Кожен PHP-проєкт нижче ганяє статичний аналіз і автоматичний набір
тестів у CI на кожен пуш — не просто "у мене працює".

| Проєкт | PHPStan | Тести |
|---|---|---|
| [NyxilumCMS](https://github.com/Faneraiy14/NyxilumCMS) | рівень 6 | PHPUnit, б'є по реальній одноразовій MySQL |
| [wordpress-mcp](https://github.com/Faneraiy14/wordpress-mcp) | max | PHPUnit |
| [anylint](https://github.com/Faneraiy14/anylint) | max | PHPUnit, 111 тестів (включно з матрицею 15 мов через tree-sitter) |
| [secretscan](https://github.com/Faneraiy14/secretscan) | max | PHPUnit, 27 тестів |
| [envcheck](https://github.com/Faneraiy14/envcheck) | max | PHPUnit, 14 тестів |

(Рівень PHPStan — наскільки строга перевірка типів; `max` ловить усе,
крім власних розширень-правил; обирається окремо для кожного проєкту
на найвищому рівні, де кожна знахідка реальна, а не фальш-спрацювання
від заглушки, яку PHPStan не бачить наскрізь.)
